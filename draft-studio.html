최초 1회 준비

PC/Work가 사용하는 실행 환경에서 npm install playwright@1.56.1, npx playwright install chromium을 실행하고 OPENAI_API_KEY 및 두 블로그의 BLOGGER_BYEOL_ID, BLOGGER_NOBODY_ID를 환경변수로 설정해.

다음으로 node scripts/draft_studio_blogger.cjs login byeol 또는 login nobody로 Chromium에서 직접 Google 로그인하고, node scripts/draft_studio_server.cjs를 실행하면 돼.

ChatGPT Plus 요금과 API 사용료는 별개야. Google 로그인 쿠키와 API 키를 GitHub Secrets나 브라우저 웹페이지에 입력하지 마. 실제 Blogger 편집기 구조가 변경되면 안전상 자동 저장이 중단될 수 있어.
