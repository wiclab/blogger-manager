별셈소 기능 점검용 · 임시글

대표이미지 업로드부터 본문 저장까지, 실제 Blogger에서 제대로 작동하는지 확인하는 글입니다.

이번 테스트의 핵심은 단순히 이미지 주소가 만들어지는 것이 아니라 이미지가 글에 남는지, 모바일에서도 자연스럽게 보이는지, ALT 설명이 유지되는지 살펴보는 것입니다.

1. 이번에 테스트하는 기능

별셈소 Blogger Manager에는 대표이미지를 업로드하면 자동으로 본문 맨 위에 넣어 주는 기능을 추가했습니다. 이미지 파일을 선택하면 브라우저에서 WebP로 최적화하고 Cloudflare R2에 저장한 다음, Blogger 글 본문에 이미지 태그를 삽입합니다.

이번 테스트에서 확인할 항목
  • R2 업로드 후 이미지 주소가 생성되는지
  • 본문 맨 위에 대표이미지가 중복 없이 한 장 표시되는지
  • 이미지 ALT 설명이 저장 후에도 유지되는지
  • PC와 모바일 모두 이미지가 잘리지 않고 표시되는지
  • 저장 후 페이지를 다시 열어도 같은 이미지가 남는지

2. 파일을 업로드하면 무엇이 달라질까?

일반적으로 Blogger 편집기의 이미지 선택기를 이용해 파일을 올립니다. 이번 테스트에서는 Google 이미지 선택기를 거치지 않고 별도의 이미지 저장소에 올려 이미지 주소를 본문 HTML에서 불러오는 방식을 사용했습니다.

저장 위치Google의 Blogger 이미지 서버Cloudflare R2

참고: WebP는 이미지 형식이며, 파일마다 압축 결과가 다릅니다. 언제나 같은 용량이나 같은 화질이 보장되는 것은 아닙니다.

3. 대표이미지 ALT와 모바일 가독성

대표이미지의 ALT(대체 텍스트)는 이미지가 보이지 않을 때 내용을 설명하는 문장입니다. 검색엔진과 보조 기술에도 이미지의 의미를 전달할 수 있으므로, 실제 사진·그림의 내용을 짧고 자연스럽게 설명하는 것이 좋습니다.

ALT 예시

별셈소 이미지 업로드 테스트를 나타내는 노트북과 클라우드 업로드 일러스트

또한 이미지의 최대 너비를 제한하고 가로폭을 100%로 설정하면, 작은 화면에서도 본문 밖으로 튀어나오는 문제를 줄일 수 있습니다. 이번 테스트에서는 이미지가 본문 위에서 가운데 정렬되고 세로 비율이 유지되는지도 함께 확인합니다.

4. 저장이 끝난 뒤 확인할 것

업로드 성공과 Blogger 저장 성공은 서로 다른 단계입니다.

R2에 이미지가 업로드됐더라도, 편집 콘솔에서 저장을 누르지 않았다면 Blogger 글 자체는 바뀌지 않을 수 있습니다.

  1. 이미지 업로드 후 본문 HTML 맨 위에 이미지가 들어왔는지 확인합니다.
  2. 글을 임시저장한 뒤 다시 열어 HTML과 ALT를 확인합니다.
  3. 미리보기에서 이미지가 표시되는지 확인합니다.
  4. 필요하다면 실제 Blogger 게시물 화면과 홈 목록 썸네일도 별도로 검사합니다.

5. 자주 묻는 질문

Q. R2에 올린 이미지는 Blogger 이미지 서버에 저장되나요?

아니요. 파일은 별도의 R2 저장소에 있고, Blogger 본문은 공개 이미지 주소를 불러옵니다.

Q. 업로드된 이미지가 보이면 썸네일도 자동으로 나오나요?

반드시 그렇지는 않습니다. Blogger 테마나 피드의 썸네일 추출 방식에 따라 다를 수 있으므로 직접 확인해야 합니다.

Q. 테스트 글을 지금 공개해도 되나요?

이 글은 기능 점검을 위해 만든 임시글입니다. 검색 유입을 위한 정보성 글이 아니므로, 테스트 후에는 임시글로 보관하거나 삭제하는 편이 적절합니다.
